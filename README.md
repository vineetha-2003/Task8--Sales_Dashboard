# Task8--Sales_Dashboard
#  Sales Dashboard in Power BI

# Objective
To create an interactive dashboard using Power BI that visualizes sales trends over time, across regions, and product categories. The goal is to provide insights that help understand overall sales performance and top contributors.

# Dataset Used
- File: `cleaned_sales_data.csv`
- Key Fields Used:
  - `sale_date` (Date)
  - `sales_amount` (Revenue)
  - `product_category`
  - `region`
  - `quantity_sold`
  - `discount`

# Tools Used
- Power BI (Dashboard Design)
- Python (for initial data cleaning)
- GitHub (for version control and submission)

# Dashboard Highlights
- Line Chart: Monthly trend of sales using `sale_date`
- Bar Chart: Regional sales comparison using `region`
- Donut Chart: Category-wise contribution to total revenue
- KPI Cards: 
  - Total Sales (₹19.33K)
  - Total Quantity Sold (77 units)
  - Average Discount (0.59%)

# Key Insights
1. **Total sales reached ₹19.33K** with an average discount of 0.59%.
2. **October recorded the highest monthly sales**, hinting at seasonal demand.
3. **Furniture (28.17%) and Food (25.11%)** were the top-performing product categories.
4. **North region led in revenue**, followed by East and West.
